Architecture & Features

Engineered for speed, privacy, and precision.

No terminal commands. No cloud uploads. No external dependencies. Tossy bundles hardware pipelines directly into your macOS workflow.

Dynamic Detection

Dynamic Window Morphing

Drop files onto Tossy and the application dynamically configures its workspace. Media files open video and audio conversion panels; code snippets trigger Code Card Studio; multi-type drops summon the Universal Canvas.

Hardware Acceleration

Apple Metal & VideoToolbox

H.264, HEVC, and ProRes encoding runs directly on Apple Silicon media engines. Color adjustments, watermarks, and image scaling execute on Metal shaders for real-time throughput.

100% Offline

Zero Network Telemetry

All operations execute locally on your physical machine. Files never travel over the network to third-party servers. Your sensitive videos, invoices, and source code stay private.

Self-Contained

Bundled Binaries

Zero prerequisite installations. Bundled standalone ffmpeg, libwebp, and libjxl binaries reside inside the application bundle. No Homebrew or command-line setup required.

Size Constraint

Frequently asked questions

Is Tossy completely free?

Yes. Tossy is free and open source software under the GNU General Public License v3.0. There are no subscriptions, paywalls, accounts, or tracking scripts.

Does Tossy send data over the internet?

Never. Every conversion, optical character recognition task, and video trim executes entirely on your local Mac processor, GPU, and media engine.

How does dynamic window detection work?

When you drag a file into Tossy, the window inspects its MIME type and extension. Dropping a video presents the video panel; dropping audio isolates audio knobs; dropping code triggers Code Card Studio; mixed batches open the Universal Canvas.

Do I need Homebrew or ffmpeg installed?

No. Tossy bundles dedicated, self-contained binaries for ffmpeg, WebP, and JPEG XL inside its application bundle, running independently without external packages.

What versions of macOS are supported?

Tossy supports macOS 14 Sonoma and macOS 15 Sequoia on both Apple Silicon (M1, M2, M3, M4) and Intel hardware architectures.

Can I compress videos for email or messaging limits?

Yes. In the Advanced controls, enter a target megabyte threshold like 25MB. Tossy runs an iterative search to find the highest bitrate that guarantees the final output fits.
